# Tatto-Maldo

Portfolio web de **Tatto-Maldo**, un proyecto desarrollado como parte del proceso de aprendizaje de desarrollo web.

## 🌐 Sitio web

- **Repositorio:** https://github.com/Dani-Maldo/Tatto-maldo
- **Sitio desplegado:** https://dani-maldo.github.io/Tatto-maldo/

> El sitio está preparado para GitHub Pages y utiliza `index.html` como página principal.

## 🛠️ Tecnologías utilizadas

- HTML5 semántico
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Bootstrap 5.3.8 mediante CDN
- Google Fonts (Montserrat)
- Git y GitHub

## 📁 Estructura del proyecto

```text
Tatto-maldo/
├── index.html
├── pages/
│   ├── contacto.html
│   ├── culturas.html
│   ├── diseños.html
│   └── variedades.html
├── styles/
│   └── styles.css
└── img/
    ├── tatuajes/
    ├── tatuajes egipcios/
    ├── Diseños/
    └── iconos/
```

## ✨ Características

- Navbar responsive de Bootstrap presente en todas las páginas.
- Menú hamburguesa para dispositivos móviles.
- Carousel de Bootstrap en la página principal.
- Galería de diseños mediante Cards y Modales de Bootstrap.
- Diseño responsive para mobile, tablet y desktop.
- Estados interactivos `:hover`, `:focus` y `:active`.
- Transiciones suaves para mejorar la experiencia de usuario.
- Estilos personalizados para mantener la identidad visual del proyecto.

## 📱 Responsive

Las páginas **Inicio**, **Diseños** y **Contacto** cuentan con adaptación para diferentes tamaños de pantalla mediante Bootstrap, CSS Grid, Flexbox y Media Queries.

## 🚀 Publicación

El proyecto puede publicarse mediante **GitHub Pages** seleccionando la rama `main` como fuente de despliegue.
